## Введение

**Points Ecosystem** — это платформа для анализа вхождения координат в заданные области с системой уведомлений в реальном времени.

- Был проведен глубокий рефакторинга: от [монолитной архитектуры на Java EE](https://github.com/georgeboiko/web-lab-4) к современной микросервисной архитектуре на Spring. 

- Внедрена Kafka для обеспечения асинхронного взаимодействие между сервисами, реализована событийная модель.

- Система полностью контейнеризирована. Настроен CI/CD пайплайн, автоматизирующий сборку артефактов, создание Docker-образов и деплой на сервер

- [Интерактивный SPA-интерфейс](https://github.com/georgeboiko/web-lab-4-front) реализован на стеке React + Redux Toolkit с адаптивной версткой

### Архитектура

В приложении реализована следующая микросервисная архитектура:

![[docs/architecture.png|800]]

1. **API Gateway** - общая точка входа в приложение. Взаимодействует с клиентом по REST API и WebSockets.
	Gateway выполняет следующие функции:
	1. Маршрутизация запросов в соответствующие им микросервисы
	2. Централизованная аутентификация
	3. Добавление необходимых заголовков к запросам - информация о пользователе, а так же служебные детали
2. **Auth service** - сервис управления доступом. Регистрация и авторизация пользователей на базе JWT (access/refresh tokens). Взаимодействует с Gateway по REST API.
3. **Points service** - отвечает за бизнес-логику анализа координат и хранение данных в PostgreSQL. Интегрирован с Kafka для публикации событий - при добавлении точки публикуется событие в топик points-added. Взаимодействует с gateway по REST API
4. **Notification service** - сервис уведомлений . Транслирует данные из топиков ```points-added``` и ```points-deleted``` пользователям через WebSockets. 
	***В перспективе:*** подписан на топик ```statistics-topic```. Полученная статистика отправляется пользователю на электронную почту.
5. ***В перспективе:*** **Analytic service** - микросервис, отвечает за сбор различной статистики. Подписан на топики ```points-added``` и ```points-deleted```. Обработанные данные публикуется в ```statistics-topic```.

### Технологии:
#### Backend:
- **Языки программирования:** Java 21
- **Фреймворки:** экосистема Spring (Cloud, Boot, Data, Security, Web MVC)
- **Инструменты:** PostgreSQL, Kafka, Docker, CI/CD
#### Frontend:
- **Языки программирования:** JavaScript 
- **Фреймворки:** React
- **Инструменты:** Redux Toolkit
